# v0.1.14 Settings Host Migration — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:executing-plans（本会话内联执行）或 superpowers:subagent-driven-development。步骤用 `- [ ]` 跟踪。

**Goal:** 把 dsh-odoo19-backup 的完整操作界面从「已安装插件」里的 `plugins.bundle.config` 卡片，迁移到 DSH 原生设置页的独立页面（`settings.section`），并移除旧入口；后端、协议与安全边界零改动。

**Architecture:** 只换前端宿主。`client.js` 的 `mountCard()` 改为注册 `settings.section`（并加 `settings.section.icon`），`OdooBackupPanel` 组件内部一行不改；`index.js` 路由与 `lib/*` 业务逻辑完全不动。

**Tech Stack:** 纯 JS ESM Client 工厂（`window.__ModuleLoader__.load`）、React（宿主提供）、`node:test`。

**Spec:** 本会话用户方案《DSH Odoo19 Backup v0.1.14 UI 迁移实施方案》（2026-11-09），以及 P1 源码确认结果。

**P1 源码确认结果（已实证，作为本计划的唯一 API 依据）**

| 项 | 事实 | 证据来源 |
|:--|:--|:--|
| 页面宿主插槽 | `settings.section`，`kind: 'list'`，`scope: 'root'`，purpose="One settings page per list entry." | 运行中宿主 `Slots.listSubTree` |
| 注册选项 | `id`（必填，自有 id 会新增一格；复用内置 id 会顶替那一格）、`order`（默认 0）、`label`（string 或 thunk，逐次读取） | 同上 `catalog.registration` |
| 组件 props | ownerProps `{ close: () => void }` + 标准 hooks + `inject` 注入 | 同上 `catalog.ownerProps` |
| 图标插槽 | `settings.section.icon`，同 `id`/`order`/`label`，组件收 `{ size }` | `dsh-better-sidebar` 实现 + 该槽 live 目录 |
| 生命周期 | `slots.inject(key, cb) → 幂等 disposer`；`register(...) → disposer`；随 fiber 卸载级联 | Client `Service.listService('slots')` |
| 同版本先例 | `remote-ssh`（id `remote-ssh`, order 200）、`better-sidebar`（id `better-sidebar`, order 100）均以此挂整页 | 两包 `lib/client.js` |
| 凭据/配置存储 | 不变：`/passphrase-status`、`/set-passphrase`、`/unset-passphrase`、`/save-servers`、`/backup-directory` | 现有 `index.js` |

**结论：`settings.section` 即正式整页宿主，无需把界面塞进 `configForms`。** `configForms` 仅继续用于「读取/兜底写入 servers 配置」，与宿主位置无关。

## Global Constraints

- 只迁移承载位置：后端 `lib/service.js`、`lib/backup.js`、`lib/restore.js`、`lib/task-state.js`、`lib/server-lock.js`、`lib/crypto.js`、`lib/knownhosts.js` **一行不改**；`index.js` 路由不变（本次不新增/不删除路由）。
- 不改变：R10 加解密、Passphrase Credentials 存储与读取、SSH 指纹信任闸门、`confirmToken` 一次性+5 分钟+绑定目标、明文包拒绝、`runRestore()` verify-then-switch。
- 不改动用户现有服务器配置（`toogel` / `odoo.toogel.cn` / `new.toogel.cn` 在 profile `cordis.patch.yml`，本计划不触碰该文件）。
- 移除旧入口：`apply` 内不再出现 `plugins.bundle.config` 注册。
- 页面内部布局沿用现有三个 tab（服务器 / 备份 / 恢复），不重做交互。
- 语言文案走 Client locale：新增 `settings.nav`，zh/en 两份 JSON + 组件内 `dict` 回退。
- 版本保持 `0.1.14`（GitHub 尚未固化，本次作为最终 0.1.14 内容），构建后重新记录 SHA256。

- [ ] **Step 3: 实现**（替换 `mountCard` 区块）

```js
        let scope;
        let disposeSection = null;
        // 宿主：DSH 原生设置页（settings.section）。渲染器按条目缓存 inject() 结果，
        // 因此 scope 晚到时必须「注销 + 重新注册」，否则 inject 不会重新求值。
        const mountSection = () => {
          try { disposeSection?.(); } catch (_) { /* 旧 disposer 失败不影响重挂 */ }
          try {
            disposeSection = ctx.slots.inject('settings.section', () => {
              const d1 = ctx.slots.register({
                name: 'settings.section',
                id: 'odoo-backup',
                order: 210,
                label: () => t('settings.nav'),
                inject: () => ({ scope, locale }),
              }, OdooBackupPanel);
              const d2 = ctx.slots.inject('settings.section.icon', () => ctx.slots.register({
                name: 'settings.section.icon',
                id: 'odoo-backup',
                order: 210,
                label: () => t('settings.nav'),
              }, OdooNavIcon)) ?? null;
              return () => { try { d2?.(); } catch (_) {} try { d1?.(); } catch (_) {} };
            }) ?? null;
          } catch (err) {
            console.warn('[dsh-odoo19-backup] 设置页注册失败：', err?.message ?? String(err));
          }
        };
        mountSection();
```
