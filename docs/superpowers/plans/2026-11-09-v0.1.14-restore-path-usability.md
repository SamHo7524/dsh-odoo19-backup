# v0.1.14 恢复路径易用性修复 — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复「恢复入口粘贴带引号/斜杠路径 → 报备份包不存在」，并在备份成功后把最终 `.tar.enc` 权威路径回填到恢复输入框；全程不削弱任何安全校验。

**Architecture:** 新增两个纯函数模块 `lib/restore-path.js`（路径规范化）与 `lib/completed-package.js`（从 `completed.json` 解析并验证最终加密产物）。在 **4 个恢复入口**（service / Agent 工具 / Host UI 路由 / Client UI）统一以 `normalizeRestorePath()` 产出「用于 token 绑定与文件检查」的规范路径；因 `service.restore` 是最内层且所有入口必经，规范化只需在 `service.restore` 内做一次即可保证一致性，但 token 的 `precheck` 与 `restore` 必须在**同一规范化值**上绑定，故 `tools.js` 的 precheck/restore 与 `index.js` 的 /precheck、/restore 也调用同一纯函数（幂等）。回填逻辑走新增 Host 路由 `/last-backup`，UI 只在「点击备份且返回成功」时调用，由服务端依据 `completed.json` 二次核验后才回填。

**Tech Stack:** Node 24 ESM、`node:test` + `node:assert`、原生 `fs/promises`、React（Client 侧，`window.__ModuleLoader__.load` 形态）、无新增外部依赖。

### Task 1: `lib/restore-path.js`（路径规范化纯函数）

**Files:**
- Create: `lib/restore-path.js`
- Test: `test/restore-path.test.js`

**Interfaces:**
- Produces: `export function normalizeRestorePath(raw): string`

规则（必须严格实现，顺序固定）：
1. `String(raw ?? '')`；
2. `.trim()` 去首尾空白；
3. 当且仅当长度 ≥ 2、首字符是 `"`、末字符是 `"` 时，去掉这一对引号（单侧/不匹配的引号**保留**）；去掉后**不再**二次 trim（避免把 ` " K:/x " ` 这类猜成路径）；
4. 当 `process.platform === 'win32'`（或显式 `opts.platform === 'win32'`）时，把所有 `/` 替换成 `\`；非 Windows 场景保留 `/`；
5. 返回规范化字符串，**不校验存在性、不猜测路径**。

/**
 * v0.1.14 — 恢复包路径规范化（纯函数，无 IO）。
 * 规则见 docs/superpowers/plans/2026-11-09-v0.1.14-restore-path-usability.md。
 */
export function normalizeRestorePath(raw, opts = {}) {
  let s = String(raw ?? '').trim();
  if (s.length >= 2 && s.startsWith('"') && s.endsWith('"')) {
    s = s.slice(1, -1);
  }
  const platform = opts.platform ?? process.platform;
  if (platform === 'win32') s = s.replace(/\//g, '\\');
  return s;
}

6. 通过则返回 `{ ok:true, localPath }`（规范后的路径）。

`deps` 可注入 `{ readdir, readFile, stat, detectFormat }` 便于测试（默认从 `node:fs/promises` 与 `lib/crypto.js` 取）。

```js
/**
 * v0.1.14 — 从 completed.json 解析「最终加密备份包」权威路径（只读）。
 * 只有后端已确认成功、产物存在且为加密格式时才允许回填恢复输入框。
 */
import { readdir, readFile, stat as fsStat } from 'node:fs/promises';
import { join } from 'node:path';
import { detectFormat as realDetectFormat } from './crypto.js';
import { normalizeRestorePath } from './restore-path.js';

const ENCRYPTED = new Set(['dsh-odoo', 'age', 'openssl']);

export async function resolveLastBackup(backupDirectory, deps = {}) {
  const readdirFn = deps.readdir ?? readdir;
  const readFileFn = deps.readFile ?? readFile;
  const statFn = deps.stat ?? fsStat;
  const detectFormat = deps.detectFormat ?? realDetectFormat;
  const root = String(backupDirectory ?? '').trim();
  if (!root) return { ok: false, reason: '备份目录为空' };

  let candidates = [];
  let days;
  try { days = await readdirFn(root, { withFileTypes: true }); }
  catch { return { ok: false, reason: '备份目录不可读' }; }
  for (const day of days) {
    if (!day.isDirectory() || !/^\d{8}$/.test(day.name)) continue;
    const dayDir = join(root, day.name);
    let tasks;
    try { tasks = await readdirFn(dayDir, { withFileTypes: true }); } catch { continue; }
    for (const task of tasks) {
      if (!task.isDirectory()) continue;
      const cp = join(dayDir, task.name, 'completed.json');
      let doc;
      try { doc = JSON.parse(await readFileFn(cp, 'utf8')); } catch { continue; }
      if (!doc || doc.completed !== true) continue;
      candidates.push({ localPath: doc.localPath, finishedAt: String(doc.finishedAt ?? '') });
    }
  }
  if (!candidates.length) return { ok: false, reason: '无已完成备份记录' };
  candidates.sort((a, b) => b.finishedAt.localeCompare(a.finishedAt));

  for (const c of candidates) {
    if (typeof c.localPath !== 'string' || !c.localPath.trim()) continue;
    const p = normalizeRestorePath(c.localPath);
    if (!/\.tar\.enc$/i.test(p)) continue;               // 拒绝分片目录明文 .tar
    let st;
    try { st = await statFn(p); } catch { continue; }
    if (!st || typeof st.isFile !== 'function' || !st.isFile() || !(st.size > 0)) continue;
    let fmt;
    try { fmt = await detectFormat(p); } catch { continue; }
    if (!ENCRYPTED.has(fmt)) continue;                    // 格式验证：必须加密
    return { ok: true, localPath: p };
  }
  return { ok: false, reason: '最终加密产物不存在或格式校验未通过' };
}
```
